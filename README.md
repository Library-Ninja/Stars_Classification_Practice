# Stars_Classification_Practice
This python program cleans a dataset on stars and uses the Scikit Learn library to create simple classification algorithms to predict the star type based on features such as color, temperature, luminosity, etc. Different classification models are evaluated by comparing their macro f1 scores.

The dataset is the Astronomical Data (Stars Data Analysis 2024) dataset from Raja Ahmed Ali Khan on Kaggle.
Raja Ahmed Ali Khan. (August 2024). Astronomical Data. Retrieved 7/31/26 from https://www.kaggle.com/datasets/datascientist97/astronomical-data.
